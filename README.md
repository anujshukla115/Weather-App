# Weather-App
🌦️ **Built a Modern Weather Forecast Dashboard!** 🚀

Excited to share my latest frontend project — **Nebula Weather**, a sleek and responsive weather application built using **HTML, CSS, JavaScript, and OpenWeatherMap API**. ✨

### 🔥 Features

✅ Real-time weather updates
✅ Current temperature & weather conditions
✅ 5-Day Forecast
✅ Humidity, Wind Speed & Feels Like Temperature
✅ Sunrise & Sunset Information
✅ City Search Functionality
✅ World Cities Weather Tracker
✅ Custom Animated Weather Icons (Sun, Cloud, Rain, Snow, Thunderstorm, Wind, Mist, Haze)
✅ Glassmorphism UI & Modern Design
✅ Responsive Layout for All Devices
✅ Geolocation-Based Weather Detection

### 🛠️ Tech Stack

🔹 HTML5
🔹 CSS3
🔹 JavaScript (ES6+)
🔹 OpenWeatherMap API
🔹 Local Storage

### 📚 What I Learned

* Working with REST APIs and asynchronous JavaScript
* Handling geolocation and real-time data
* Dynamic UI updates based on weather conditions
* Local storage management
* Building modern responsive interfaces with glassmorphism effects

This project helped me strengthen my frontend development skills while creating a practical application that users can use every day.
